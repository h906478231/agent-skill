# explainer-video-narration Specification

## Purpose
讲解视频的配音与运行环境：可插拔 TTS（默认 Piper，在线引擎二次确认）、配音驱动动画时长、`.srt` 生成与硬字幕、uv 独立环境与 `doctor` 自检。
## Requirements
### Requirement: Narration SHALL drive animation timing

Each segment SHALL be rendered inside a voiceover block, so that the animations of the segment take the duration of the generated narration audio. Animations SHALL NOT be cut before the narration of their segment ends.

#### Scenario: Long narration
- **WHEN** the narration audio of a segment lasts 9 seconds and its actions have a default length of 3 seconds
- **THEN** the actions are stretched or followed by a wait so the segment lasts 9 seconds

### Requirement: TTS engines SHALL be pluggable with Piper as default

The skill SHALL provide a TTS engine interface. The default engine SHALL be Piper with a Chinese (zh_CN) voice and SHALL run offline. The skill SHALL also provide the online engine edge-tts.

#### Scenario: Default engine
- **WHEN** the storyboard sets no TTS engine
- **THEN** the narration is generated by Piper without network access

### Requirement: Online TTS SHALL require a second confirmation

When the selected engine sends text to an external service, the render command SHALL refuse to run unless the flag `--allow-online-tts` is given. The `/opsx:video` command SHALL ask the user to confirm before it adds the flag, and SHALL state that the narration text will be sent to the external service.

#### Scenario: Online engine without the flag
- **WHEN** the storyboard sets `tts: edge` and render runs without `--allow-online-tts`
- **THEN** the render command exits with code 1 and states that the narration would leave the machine

### Requirement: Subtitles SHALL be produced as SRT and burned in

The render command SHALL produce `video/explainer.srt` from the segment narration and the audio timing. Subtitle entries SHALL be in time order and SHALL NOT overlap. The final `video/media/explainer.mp4` SHALL contain the Chinese subtitles burned in with a CJK font.

#### Scenario: SRT timing
- **WHEN** rendering finishes
- **THEN** `explainer.srt` has one or more entries per segment, start times increase, and no entry ends after the next entry starts

### Requirement: Python dependencies SHALL run in a uv-managed environment

The render command SHALL run the scene runner with uv using the pinned dependencies of the skill. The environment SHALL be stored outside the skill directory, in a user cache path. The command SHALL NOT use the system Python and SHALL NOT install system packages.

#### Scenario: First render
- **WHEN** render runs for the first time on a machine with uv installed
- **THEN** uv creates the environment in the cache path and the skill directory stays unchanged

### Requirement: doctor SHALL check every dependency and SHALL NOT install

The skill SHALL provide a `doctor` command that checks uv, the Python environment, Manim, manim-voiceover, ffmpeg with the subtitle filter, the selected TTS engine and voice model, a CJK font and the `.gitignore` entry. For each missing item it SHALL print the install instruction. It SHALL NOT install anything.

#### Scenario: ffmpeg without subtitle filter
- **WHEN** ffmpeg is installed without libass support
- **THEN** `doctor` reports the subtitle filter as missing and prints the install instruction
