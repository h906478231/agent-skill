# 中文 STE 规则表（唯一事实源）

> 本文件是中文 STE 写作规则的唯一事实源。`scripts/ste-lint.mjs config-snippet` 从下方「采纳的规则」表生成 `openspec/config.yaml` 的 `rules` 片段；`shared/reply-rules.md` 引用本文件约束对话回复。修改规则只改本文件，再重新生成片段。

## 来源与版权边界

- 骨架：ASD-STE100 Simplified Technical English，Issue 9（2025-01）。下表「← STE」列的编号已逐条对照 Issue 9 原文核对。
- 本表**只引用规则编号**，规则内容全部用中文自行复述，不复制原文（ADR-0005）。
- 通用受控词表（`shared/vocabulary.yaml`）按 STE 原则自行编写，不是 ASD 官方词典的翻译或摘录。
- 技术名词与技术动词由项目根 CONTEXT.md 承接；`_Avoid_` 列出的叫法是禁用别名（ADR-0003）。

## 阈值与计数口径

- 默认阈值：描述句 40 字（C-R6.3）、指令句 30 字（C-R5.1）、段落 6 句（C-R6.6），定义在 `shared/vocabulary.yaml`，项目可在 `openspec/ste.yaml` 覆盖。
- 40 / 30 字由 STE 的 25 / 20 词按**约 1.5 字/词**折算。该折算比是经验值，未经验证，因此句长规则只告警。
- 计数：每个汉字计 1；连续的英文字母或数字计 1；标点不计。代码、URL、文件路径在计数前删除。
- 句子切分：按「。」「！」「？」、英文句末标点与换行切分。标题行、表格行不计句长。
- 指令句：带复选框的任务行（`- [ ]`）与有序列表项；其余句子都按描述句处理。项目可以调整阈值，不能调整判定方式。

## 检查方法说明

| 规则 | 判定方式 |
|---|---|
| C-R1.11 禁用别名 | 子串匹配 CONTEXT.md `_Avoid_`；落在更长的术语内不报告 |
| C-R1.1 非受控通用词 | 子串匹配词表的非受控词；落在该条目的例外短语内或更长的术语内不报告 |
| C-R4.1 模糊词 | 子串匹配模糊词清单；例外短语同上 |
| C-R2.1 名词串 | 按虚词与标点拆分后，仍有连续 12 个及以上汉字 |
| C-R3.6 被动语态 | 出现「被」字句（「被动」等词除外） |
| C-R5.2 程序步骤 | 指令句含「并」「然后」「；」（「并发」「合并」等词除外） |
| C-R7.2 安全提示 | 「警告」「注意」开头的句子，后文不以词表 `safetyStarts` 中的命令词或条件词开头 |

所有检查都跳过围栏代码块、行内代码、URL、文件路径、标识符与 HTML 注释；对话回复另外跳过 markdown 引用块。行内 `<!-- term-allow: 词 -->` 豁免该行的这个词。
