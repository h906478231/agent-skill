# ADR-0012: 事实预调研交给只读子 agent，explore 的讨论仍留在主会话

- 状态：已接受
- 日期：2026-11-15
- 决策者：agent-skills 团队（用户 2026-11-15 在 `/opsx:grill` 中确认）
- 关联变更：`openspec/changes/add-fact-research`
- 补充：决策 ⑪（2026-10-23，explore 保留在主会话，不下放子 agent，不写 `discussion-log.md`）
- 编号说明：ADR-0011 已由 `add-autopilot-loop` 的 design D14 预定

## 背景

explore 混合了两件事：查明代码现状与外部事实，以及与用户讨论方案取舍。决策 ⑪ 把 explore 整体留在主会话，原因是讨论下放后内容会缺失，导致方案偏离。取证部分因此也在主会话中进行，讨论开始前要先花时间读代码，主会话的上下文也带上了全部取证过程。grill Step 3 已经把事实交给子 agent 查证，并按 `openspec-discussion-sync` 的五段契约回流。

## 决策

1. 新增事实预调研（`/opsx:research`），由一个只读子 agent 执行，主会话只接收结论并写入变更目录的 `discussion-log.md`。没有变更目录时先确认变更名再创建，与 grill 相同。
2. 决策 ⑪ 约束的是与用户的讨论，不约束只读取证。explore 本身不下放、不写 `discussion-log.md`，这两条不变。
3. 事实预调研只写事实与出处，不写推荐方案：五段契约保留，「建议落点」只能写「带入 explore 讨论：<问题>」，「弃案」只写被事实排除的路径并写出依据。原因：调研结论写成方案倾向时，会在讨论开始前锚定结果。
4. explore 只在本仓自加区增加一句：变更目录有 `discussion-log.md` 时先读其中的事实预调研记录。上游段落不修改。
5. 只追加，不改旧内容：回流表写一行摘要，表下追加「### D<n> 事实预调研：<主题>」小节写完整五段。每条事实编号 `D<n>-F<m>`；新一轮发现旧事实不再成立时写「取代 D<n>-F<m>：<原因与新依据>」，读取方跳过已取代的事实。原因：讨论引用过的原文要能找回；完整内容放在 `discussion-log.md` 中，不新增产物位置，不修改门禁脚本的产物允许清单。

## 备选方案

| 方案 | 结论 |
|---|---|
| 把 explore 整体下放给子 agent | 否决：违反决策 ⑪，讨论内容缺失 |
| 主会话直接执行取证 | 否决：主会话上下文带上全部取证过程，与不预调研差别小 |
| 事实预调研另定只含事实的格式 | 否决：要另定一套回流规则；保留五段只需在 `openspec-discussion-sync` 加一种小节与取代写法 |
| 完整内容写成单独文件 `research/D<n>.md` | 否决：要修改门禁脚本的产物允许清单，与另外三个修改该脚本的变更冲突 |
| 新一轮修改旧事实的状态 | 否决：不再只追加，讨论引用过的原文会被改掉 |
| 并入 `add-autopilot-loop` 作为托管的第一阶段 | 否决：要修改托管的入口模型，R4 签字作废并重走评审 |

## 后果

- 同一个只读取证有两个入口：grill Step 3 的查证子 agent（访谈中按需）与事实预调研（explore 之前）。grill 不改用事实预调研。
- 按云舟任务号运行时由主会话只读取任务，不写云舟；子 agent 不运行 `flows-cli`。
